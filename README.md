# ניהול לקוחות + דוח חודשי מבוסס Gmail

תוכנה רגילה למחשב שלך - מתקינים אותה כמו כל תוכנה (Setup.exe, "הבא הבא
סיום"), מקבלים אייקון בשולחן העבודה, ופותחים בלחיצה כפולה. אין צורך
בשום שורת פקודה בשימוש היומיומי.

התוכנה שומרת רשימת לקוחות, מתחברת לכל חשבונות ה-Gmail של העסק שלך
(למשל: כללי / מכירות / תמיכה), סופרת כמה מיילים הוחלפו מול כל לקוח -
**מאוחד משלושת החשבונות יחד, כולל זיהוי כפילויות מ-CC** - ומפיקה דוח
חודשי אחד (נפתח בדפדפן) שמראה גם את הסה"כ וגם פילוח לפי חשבון.

---

## איך משיגים את קובץ ההתקנה (Setup.exe)

קובץ Setup.exe הוא קובץ Windows, וכדי לבנות אותו צריך שרת/מחשב Windows
בפועל. יש 2 דרכים לקבל אותו - האפשרות הראשונה לא דורשת שום דבר מותקן
אצלכם, רק דפדפן:

### אפשרות א' (מומלץ) - בנייה אוטומטית בענן, בלי מחשב Windows בכלל

GitHub (אתר חינמי לאחסון קוד) מציע שרתי Windows בענן שבונים את זה
בשבילכם אוטומטית. זה כבר מוכן בתיקייה (בתיקיית `.github`), רק צריך
להעלות את הקבצים:

1. גשו ל-https://github.com וצרו חשבון חינמי (אם אין לכם)
2. לחצו על **+** למעלה → **New repository**. תנו שם (למשל `client-manager`),
   השאירו **Public**, ולחצו **Create repository**
3. באתר של המאגר החדש, לחצו **Add file → Upload files**
4. גררו לתוכו **את כל התוכן** של התיקייה שקיבלתם ממני (כולל התיקייה
   הנסתרת `.github` - אם הדפדפן לא מעלה תיקיות נסתרות, גררו את כל
   הקבצים בבת אחת מחלון הקבצים של המחשב, לא אחד-אחד)
5. גללו למטה ולחצו **Commit changes**
6. עברו ללשונית **Actions** שבמאגר - תראו ריצה שמתחילה אוטומטית
   ("Build Windows Installer"). המתינו כ-2 דקות שתסתיים (עיגול ירוק ✓)
7. לחצו על הריצה שהסתיימה, גללו למטה ל-**Artifacts**, ולחצו על
   **ClientManager-Setup** להורדה - זה קובץ ZIP שבתוכו `ClientManager-Setup.exe`

זהו - זה קובץ ה-Setup האמיתי, מוכן להתקנה על כל מחשב בעסק.

**הערה:** המאגר יהיה ציבורי (כל אחד יכול לראות את הקוד, לא את הנתונים
שלכם - הנתונים נשמרים רק על המחשב שמריץ את התוכנה). אם חשוב לכם
שהקוד יהיה פרטי, אפשר לבחור **Private** בשלב 2 - זה גם חינמי.

### אפשרות ב' - בנייה עצמאית על מחשב Windows

אם יש לכם מחשב Windows ותעדיפו לבנות בעצמכם:
1. התקינו **Python** (https://www.python.org/downloads/, סמנו
   "Add python.exe to PATH")
2. התקינו **Inno Setup** (חינמי, https://jrsoftware.org/isdl.php)
3. לחצו פעמיים על **`build_installer.bat`** בתיקיית התוכנה
4. לאחר כדקה-שתיים, קובץ ההתקנה מוכן ב-`Output\ClientManager-Setup.exe`

## התקנה בפועל (על כל מחשב שרוצים)

לחיצה כפולה על `ClientManager-Setup.exe` → הבא → הבא → סיום.
מתקבל אייקון בשולחן העבודה ובתפריט התחלה, בדיוק כמו כל תוכנה אחרת.
גם הסרת התקנה עובדת רגיל, דרך "הגדרות ← אפליקציות" של ווינדוס.

## שימוש - הפעלה ראשונה

פותחים את התוכנה מהאייקון בשולחן העבודה. יש 4 לשוניות:

### 1. לשונית "הגדרות" - חיבור חד-פעמי ל-Google
כדי שהתוכנה תוכל לגשת ל-Gmail שלך, גוגל דורשת "קובץ הרשאות" אישי -
זה חינמי אבל דורש כמה צעדים אצל גוגל (לא בתוכנה עצמה):

1. גש ל-https://console.cloud.google.com/ וצור פרויקט חדש (שם כלשהו)
2. **APIs & Services → Library** → חפש **Gmail API** → **Enable**
3. **APIs & Services → OAuth consent screen** → בחר **External** →
   מלא שם ומייל → שמור. במסך **Test users** הוסף את **שלושת** כתובות
   ה-Gmail העסקיות שלך (לא רק אחת!)
4. **APIs & Services → Credentials → Create Credentials → OAuth client ID**
   → סוג: **Desktop app** → **Create**
5. **הורד** את הקובץ שנוצר (יישמר בתיקיית ההורדות למשל)

עכשיו חוזרים לתוכנה, לשונית "הגדרות", ולוחצים **"בחר קובץ הרשאות"** -
בוחרים את הקובץ שהורדתם. זהו, גמרתם עם השלב הזה לתמיד.

### 2. לשונית "לקוחות"
לוחצים "+ הוסף לקוח" וממלאים שם + אימייל לכל לקוח.

### 3. לשונית "חשבונות Gmail"
לוחצים "+ חבר חשבון Gmail", נותנים כינוי (כללי / מכירות / תמיכה),
נפתח דפדפן - מתחברים ומאשרים גישה (read-only בלבד - התוכנה רק *קוראת*
מיילים, לא שולחת ולא מוחקת). עושים זאת פעם אחת לכל אחד משלושת החשבונות.

### 4. לשונית "סנכרון ודוחות"
בוחרים חודש ושנה, לוחצים **"סנכרן מה-Gmail"**, מחכים שיסיים (רואים
התקדמות ביומן הפעילות למטה), ואז לוחצים **"הפק דוח ופתח"** - הדוח נפתח
אוטומטית בדפדפן.

## איך התוכנה סופרת "פעולות"
כל מייל שנשלח אליך מלקוח, או שנשלח ממך אל לקוח - מכל אחד משלושת
החשבונות - נספר כפעולה אחת, מזוהה לפי כתובת המייל של אותו לקוח. הדוח
מציג סה"כ מאוחד לכל לקוח, ולצידו פילוח כמה פעולות היו מול כל חשבון.

**זיהוי כפילויות (CC בין חשבונות):** אם אותו מייל בדיוק נשלח/הועתק
לשניים משלושת החשבונות במקביל, התוכנה מזהה זאת אוטומטית (לפי מזהה
ייחודי של המייל) וסופרת אותו פעם אחת בלבד. בדוח יופיע סימון "גם ב: ..."
ליד מיילים כאלה.

## פרטיות
כל הנתונים (לקוחות, נתוני מיילים, דוחות) נשמרים אך ורק על המחשב שלך,
בתיקיית ההתקנה. שום מידע לא נשלח לשום שרת חיצוני (מלבד ל-Gmail עצמו,
כדי לשלוף את המיילים שביקשתם).

## נספח - למשתמשים מתקדמים
קיימת גם גרסת שורת-פקודה (`main.py`) לאוטומציה, אם תרצו בעתיד:
```bash
python main.py sync --year 2026 --month 8
python main.py report --year 2026 --month 8
```
